# INSTALL
1. format your drive in rufus like this:
<img width="467" height="538" alt="image" src="https://github.com/user-attachments/assets/742d52de-bdd0-4a75-8903-9af22b1c9328" />

### JUST PRESS START, DON'T TOUCH ANY OTHER SETTINGS
2. create a folder called 'EFI' and place it in the root of your usb.
3. put 'BOOT' and 'OC' in 'EFI'
4. get com.apple.recovery for MACOS MONTEREY, other version do not work
(get it from opencore's github guide)
5. Boot the drive and select your drive
